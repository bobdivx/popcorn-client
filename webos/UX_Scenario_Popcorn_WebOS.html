0. Document Purpose and Scope

This document is the official UX Scenario for LG Seller Lounge QA. It describes how Popcornn works on LG webOS TV, how to test it with the Magic Remote / D-pad, expected results, and acceptance criteria for each scenario.

Scope: Launch, first-time setup, login, home browsing, search, detail, playback, settings, logout, exit, and error handling.

Out of scope: Server-side administration of the Popcornn backend (except using the provided QA test account).

1. Application Overview

Popcornn is a media client for LG webOS TV. It connects to a Popcornn backend server and allows the user to:

  • Browse movies and TV series from a personal media library / discovery catalog
  • Search content
  • Open title details and start video playback on the TV
  • Manage basic client settings (language, server URL, account)

Important for QA: A preconfigured backend and test account are provided below. No seller-owned private server setup is required for pretest / functional QA.

5. Step-by-step User Flows

5.1 Scenario 1 — Application Launch

Steps:
  1. From LG Content Store or TV Launcher, focus Popcornn and press OK.
  2. Wait for splash / loading indicator.
  3. Observe the first interactive screen (setup wizard on first run, otherwise home or login).
Expected results:
  • No black screen freeze longer than ~15 seconds on a normal connection.
  • No crash / forced close.
  • Visible brand mark Popcornn on loading / first screen.
Acceptance criteria:
  1. App process starts and renders UI.
  2. Remote focus is visible on a focusable element.

5.2 Scenario 2 — First-time Setup

Steps:
  1. On first launch, complete the setup wizard.
  2. Select language (English or French) with arrows + OK.
  3. Confirm or enter Server URL: https://popcorn-vercel.vercel.app.
  4. Accept terms / disclaimer if shown.
  5. Continue to Login.
Expected results: Each wizard step is reachable with remote only; user can proceed and go back within the wizard. Acceptance criteria: Wizard completes without keyboard/mouse; invalid URL shows an error if connection test is offered.

5.3 Scenario 3 — Authentication

Happy path:
  1. On Login, enter email lg-test@popcorn-app.com.
  2. Enter password LGTest2026!Secure.
  3. Focus Sign in and press OK.
Expected: User reaches Home / Discover content screen.

Negative path: Enter a wrong password → error message; stay on login; no crash.

5.4 Scenario 4 — Home Navigation

Steps:
  1. From Home, move focus across side navigation (Home / Search / Settings / etc.).
  2. Move focus across horizontal content rows (Continue Watching, Popular Movies, Popular Series, Recent).
  3. Press OK on a poster to open detail.
  4. Press Back to return to the row / home.
Expected: Focus ring always visible; content loads or shows empty state; Back does not exit until user is at root.

5.5 Scenario 5 — Search

Steps:
  1. Open Search from the menu.
  2. Enter a common title query using the on-screen keyboard (example: love or star).
  3. Review results grid; open one result with OK.
  4. Search a nonsense string (example: xyznonexistent123) and verify empty state.
Expected: Results or “no results” message; no endless spinner without message.

5.6 Scenario 6 — Content Detail and Playback

Steps:
  1. Open any available title detail (poster → OK).
  2. Focus Play (or equivalent) and press OK.
  3. During playback: OK toggles play/pause (or shows controls then toggles).
  4. Left/Right seek when controls are visible (if supported for the stream).
  5. Press Back: first press may show/hide controls; further Back exits player to detail/list.
Expected: Video or clear playback status; audio if stream has audio; return path via Back works.

5.7 Scenario 7 — Settings and Logout

Steps:
  1. Open Settings from navigation.
  2. Verify at least: server / account / language related entries are visible or reachable.
  3. Perform Logout.
Expected: User returns to login (or setup) and must authenticate again to browse library content.

5.8 Scenario 8 — Error Handling

5.9 Scenario 9 — Exit Application

Steps: From Home root, press Back repeatedly and/or press Home. Expected: App closes to TV launcher, or shows an exit confirmation then closes. No hang.

6. Detailed Screen Descriptions

6.1 Splash / Loading

Popcornn logo / loading animation. Temporary screen while HTML assets and session bootstrap.

6.2 Setup Wizard

Language selector; server URL field; terms acceptance; Continue / Back actions. Fully remote operable.

6.3 Login

Email field, password field, Sign in button. Default focus on email. Error region for failed auth.

6.4 Home / Discover

Side menu + horizontal rows of posters. Focusable posters and menu items. Optional hero / featured area.

6.5 Search

Search field / OSK, results grid, empty state.

6.6 Detail

Poster/backdrop, title, synopsis, Play CTA; for series, season/episode list when applicable.

6.7 Player

Full-screen video surface; transport controls (play/pause/seek); Back exits player hierarchy as in Scenario 6.

6.8 Settings

List/panels for server, account, language/preferences, logout.
